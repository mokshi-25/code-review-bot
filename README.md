# 🔍 Code Review Bot

An AI-powered code review tool built with vanilla JavaScript and the Anthropic Claude API.

**Live demo:** https://mokshi-25.github.io/code-review-bot/public/index.html

## Features

- Paste code or drag and drop a file
- Auto-detects the language from the file extension
- Scores code on readability, performance, security and maintainability
- Lists bugs, improvements and positives
- Demo mode: shows a sample review when no API key is saved
- Real reviews: paste your own Anthropic API key (kept only in your browser)
